Random Soft Prompts

Soft-prompt methods improve reasoning by inserting trained vectors into the input, but whether the gain comes from the learned content or from the act of injection has not been separated. We study the simplest possible soft prompt: a Random Soft Prompt (RSP) drops the training step and appends a freshly drawn sequence of random embedding vectors to the input.

Each vector is sampled from an isotropic Gaussian fitted to the entrywise mean and variance of the pretrained embedding table, so it has the scale of a real token but no preferred direction. The sequence carries no learned content, yet it reaches accuracy comparable to optimized soft prompts (TTSV[1], SoftCoT[2], LTPO[3]) on MATH-500, GSM8K, and AIME24.

hj ~ N(μE·1, σE2·I), j = 1 … L, input = [X ; H]

The same holds across injection positions and model families. Where the baseline is already strong, suffix RSP matches it. On the harder AIME24 it adds a few points. When a base model is evaluated with a chat template it was never trained on, a random prompt recovers much of the lost accuracy.

Content or injection? Replace the trained vectors and see.

We keep each method's injection length and position fixed and only change what is injected. Replacing all trained vectors with random draws does not consistently hurt. Shuffling token order or permuting coordinates inside each vector, which destroys the learned structure but keeps the norms, does not hurt either. The channel is not inert: overtraining the same vectors with a 1000× learning rate collapses accuracy.

Branch early, anneal later.

RSP flattens the distribution over the first few generated tokens: entropy and varentropy go up, top-1 probability goes down, and the curves return to the baseline within a few percent of the generation. Optimized soft prompts show the same early pattern despite different training objectives.

The mechanism is attention mass. With a fixed number of RSP tokens and a growing KV cache, the share of attention on the random positions shrinks as generation proceeds, so the perturbation that opened a new branch fades and the response commits to a single completion.

Diversity that turns into Pass@N.

Temperature rescales the same distribution and never changes the ranking of tokens. RSP reranks: the Spearman correlation with the baseline first-token distribution is 0.71 instead of 1.0. Matching RSP's distributional shift with temperature alone (τ = 3.0) drops accuracy to 1.4%, while RSP keeps 73.3%.

Drawing a fresh RSP for every sample and combining it with temperature sampling gives the highest Pass@N on both MATH-500 and AIME24. Sharing one RSP across samples gives no gain, so the benefit comes from varying the perturbation, not from any single one.

Beyond inference: better training data.

If RSP finds correct solutions that plain sampling misses, it should help rejection-sampling fine-tuning. On 32,737 hard problems that Qwen2.5-Math-7B-Instruct solves at most once in four clean rollouts, we draw eight rollouts per problem with and without RSP, keep the correct ones, fine-tune the same model on each set, and evaluate without RSP.
